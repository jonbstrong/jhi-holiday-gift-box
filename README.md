# Jackson Heights Insider Holiday Gift Box

Astro static landing page for Cloudflare Pages. The page remains in prelaunch mode until the final guaranteed assortment, pickup workflow, refund and cancellation policy, Stripe quantity limits, and confirmation emails are verified.

Build with `npm install` and `npm run build`. Cloudflare Pages build command: `npm run build`; output directory: `dist`; production branch: `main`.
